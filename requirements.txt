# Python package requirements.
#
#   pip install -r requirements.txt
#
# SCOPE: this covers the WEB INTERFACE ONLY.
#
# The analysis scripts -- fastq_qc_clean.py, align_reads.py,
# comprehensive_variant_calling.py, pipeline_orchestrator.py,
# pcgr_report.py and coverage_report.py -- import nothing outside the Python
# standard library and will run against a bare Python 3.8+ with this file
# never installed.
#
# They do, however, need the external bioinformatics TOOLS (fastp, bwa-mem2,
# samtools, GATK, bcftools, SnpEff). Those are not pip packages; install them
# with conda/mamba via environment.yml, or see install.md.
#
# PDF generation deliberately adds no dependency: webapp/pdfwriter.py emits
# PDF directly using the standard-14 fonts, so reportlab, WeasyPrint and
# wkhtmltopdf are all unnecessary.
#
# The TEST SUITE adds nothing either: run_tests.py and everything under
# tests/ use the standard library's unittest, so the suite runs on a fresh
# clone before any environment exists. Tests that exercise the web
# interface skip themselves when Flask is absent.
#
# ONE development-only exception: docs/make_diagram.py renders the PNG of
# the pipeline illustration with Pillow. It is never needed to RUN an
# analysis -- only to redraw the picture in the README -- so it is
# deliberately not listed as a requirement below.

flask>=2.2
