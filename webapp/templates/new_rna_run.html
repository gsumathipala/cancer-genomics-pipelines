This is the RNA branch: splice-aware alignment with STAR, then fusion detection with Arriba. It does not call SNVs or indels — that is the DNA run form — and it does not quantify expression. A DNA and an RNA library from one specimen are two runs that belong together; link them below.

The dangerous output on this branch is a negative. A degraded FFPE RNA extraction produces a clean, well-formed, empty fusion table that is indistinguishable from a specimen carrying no fusion. Every run measures the library and says whether an empty table may be read as a negative — record the DV200/RIN below so that statement has the one number this pipeline cannot compute.

Read 2 may be left blank. Ion Torrent RNA libraries are single-end, and STAR handles that — though every paired-end assumption elsewhere in this bundle does not.

Reference data

These are filled in from what install_pipeline.py --with-rna put on disk. The STAR index bakes in the annotation and the read length: an index built for 100 bp reads works on 150 bp reads and quietly loses junction sensitivity, so the run checks the index’s build record against these values and says if they disagree.

Leave the Arriba files blank unless the run reports that it could not find them. Without the blacklist in particular, recurrent read-through artefacts are reported as high-confidence fusions and the table fills with noise.

Fusion calling

The confidence bar decides what the report counts as reportable. Calls below it are marked, never dropped — a laboratory investigating a clinically expected fusion needs to see that it was called weakly rather than to be told nothing was found.

The two floors are what the library QC verdict is measured against. They come from the panel profile and differ by an order of magnitude between chemistries: 2 M reads is a normal, adequate anchored-PCR library and a badly failed whole transcriptome.

Runtime

STAR loads the genome index into memory: expect around 32 GB of RAM for hg38. Runs are queued one at a time on this machine, which is what keeps that from colliding with anything else.
