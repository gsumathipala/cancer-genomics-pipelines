This page is about the reference data. The pipeline's own code is updated from a shell — copy a newer bundle to this machine and run python3 install_pipeline.py --update from it, then restart this app.

An upgrade runs install_pipeline.py for that one step, with --force, and re-checks afterwards so this page shows what is now installed. Upgrading mid-project is a real decision: a new VEP cache changes transcript sets and a new COSMIC changes identifiers, so a report regenerated after one can legitimately disagree with the report issued last week for the same sample.
