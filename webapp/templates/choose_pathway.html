What are you looking for?

Pick the pathway that matches the library you are about to analyse. If you are unsure, the kit’s documentation will say whether it produces a DNA library, an RNA library, or both from one specimen.

DNA — variants

Point mutations and small insertions/deletions.

  • Finds: SNVs and indels, with actionability tiers, TMB and mutational signatures where the panel is large enough.
  • Needs: the kit’s target BED.
  • Does not find: gene fusions, copy-number changes.
Start a DNA run →

RNA — fusions

Gene fusions and splice events.

  • Finds: fusions such as EML4–ALK, BCR–ABL1, NTRK rearrangements, and MET exon 14 skipping.
  • Needs: the GENCODE annotation and a STAR index (installed with --with-rna).
  • Does not find: point mutations or indels.
Start an RNA run →

Both — hybrid panel

One specimen, a DNA library and an RNA library, reported together.

  • Finds: everything both pathways find, in one clinical report.
  • Needs: both sets of reference data, and both sets of FASTQs.
  • Queues the two runs for you and links them, so the combined report happens without anyone having to remember to ask for it.

Not sure?

A DNA-only run is never wrong, only incomplete: it will miss a fusion that the specimen carries. An RNA run cannot be substituted for it — the two answer different questions and neither is a superset of the other.

If the kit produces both libraries and you run only one now, you can run the other later and link them from the RNA form; the combined report is produced then.
